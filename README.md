## Implementation

A static website built with HTML, CSS, JavaScript, and SVG. Movement and collision physics run directly in the browser, without a framework or build step.

The site lives in `index.html`, with local image and SVG assets. Serve this directory with a static HTTP server to preview it locally. The public site is hosted on GitHub Pages.
